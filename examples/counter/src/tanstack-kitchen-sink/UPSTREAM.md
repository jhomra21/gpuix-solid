# Upstream source

This native example adapts the TanStack Router Solid kitchen-sink example from the Solid 2 prerelease line.

- Repository: `TanStack/router`
- Branch: `solid-router-v2-pre`
- Pinned upstream revision: `b6984af74dd561b8ee7e2d7369898a536dda70c2`
- Source example: `examples/solid/kitchen-sink-solid-query-file-based`
- Upstream Solid runtime at the pinned revision: `solid-js ^2.0.0-rc.1`, `@solidjs/web ^2.0.0-rc.1`
- Upstream router: `@tanstack/solid-router ^2.0.0-rc.1`
- License: MIT

The GPUIX version preserves the recognizable route shell and the Dashboard / Invoices / Users interaction model, but replaces browser DOM, URL navigation, network-backed JSONPlaceholder data, TanStack Query transport, and browser devtools with deterministic local state suitable for the native renderer.
