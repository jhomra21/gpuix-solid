Solid 2 + GPUIX + GPUI

Solid components.
Native GPU windows.

GPUix Solid turns Solid's reactive tree into GPUIX native elements. GPUI paints the window with Metal, DirectX, or Vulkan. There is no Electron renderer and no browser web view.

Quickstart

Start with the native renderer.

Solid 2 apps compile through Solid's universal renderer and run as a native process with @gpuix/native.

Terminal 
bun add gpuix-solid solid-js@2.0.0-rc.8
bun add -d @solidjs/vite-plugin vite typescript
Read the Solid 2 setup guide

Scope

This site runs in a browser. GPUix Solid apps do not.

The project targets GPUIX's native desktop renderer. This website documents the project with captured native output. It does not wrap the native renderer in a browser.
